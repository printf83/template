Printing & Performance

How does the print time estimation work? ▼

The engine automatically tracks how fast your device renders pages and stores this historical performance data locally in your browser's Cache API. It uses this data to compute a running average per page and accurately estimate processing times for future print jobs.

Why do I see a "Continue Printing?" warning modal? ▼

When a document contains many pages or is calculated to take longer than 5 seconds to generate, the system displays a warning dialog to prevent accidental browser tab freezes and allow you to confirm before processing begins.

How can I reset my stored print performance statistics? ▼

Your print performance metrics (like total print speed and total page count) are stored locally in your browser cache. Clearing your browser's site data or executing db.clear() will reset these calculations back to factory defaults.

Template Expressions

How do piped template expression helpers work? ▼

You can chain multiple transformation helpers together using the % prefix inside standard handlebars syntax. For example, {{ %uppercase %money_text total }} will first format the value as currency and then convert the entire string to uppercase.

Are template helper transformations case-sensitive? ▼

Transformers like the short text formatter automatically preserve letter casing (Title Case, UPPERCASE, or lowercase) based on how you enter the property key in your dictionary schema.

Files & Clipboard

What happens when I click "Copy File"? ▼

Selecting a file converts code and data files (JSON, CSV, HTML) into plain text, and converts images into Base64 Data URLs. It then writes the output directly to your operating system clipboard so you can paste it into external applications like VS Code or Notepad.

What happens if I upload or copy a large file? ▼

Files larger than 10 MB trigger a warning dialog before processing. While you can choose to proceed, processing very large files (especially memory-intensive Base64 images) may temporarily slow down or freeze your browser tab.

Why did pasting fail after selecting a file? ▼

Some browsers suppress system clipboard writing if the web page loses active window focus while the file picker dialog is open. The application automatically recovers tab focus before executing copy requests to bypass this browser policy.

Security & Offline Support

Is my document data uploaded to an external server? ▼

No. All template evaluation, dynamic chunk loading, image conversions, and PDF generations execute 100% locally inside your web browser. None of your data is transmitted to external servers.

Does this application work offline? ▼

Yes. Heavy dependencies (such as CodeMirror, jsPDF, and html2canvas) are dynamically cached after their first load, allowing document generation to function smoothly even without an internet connection.
